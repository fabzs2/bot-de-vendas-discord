Para gerar o arquivo `.zip` limpo (sem dados sensíveis, sem seu `.env` privado e sem histórico de banco de dados), execute no terminal do projeto:

```bash

```

O arquivo final pronto para upload estará localizado em:
`dist/bot_vendas.zip`

Basta subir esse arquivo `.zip` no campo de entrega de arquivos da Kiwify!
